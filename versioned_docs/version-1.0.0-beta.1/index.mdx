# Overview

Libra is an authentication and authorization proxy in front of an NGSI-LD context broker. It authenticates the caller, decides against a policy set, narrows the request to what the policy allows, forwards it to the broker, and filters the response on its way back. Libra stores no context data.

:::warning[Open beta]

Libra is an open beta and under active development. It has not been independently audited, so do not put it in front of production data yet. [Known limitations](security/known-limitations.md) lists what this release does not defend.

:::
